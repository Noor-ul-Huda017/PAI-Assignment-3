# Programming for AI – Assignment 3

This repository contains my Programming for AI Assignment 3 for Fall 2026.

## Contents
- `Assignment3_Programming_for_AI.ipynb` – Completed assignment notebook.
- `data/` – Provided datasets (CSV, NPY and NPZ files).
- `outputs/` – Generated dashboard images, PDF and wave animation.
- `README.md` – Project information and instructions.

## How to Run
1. Install Python, NumPy, Pandas and Matplotlib.
2. Clone or download this repository.
3. Open the notebook in Jupyter Notebook or VS Code.
4. Run all cells from top to bottom.

The notebook processes sensor, weather and student data, creates visualizations, and generates a 3D surface and animated wave.

## Challenges
Handling missing and invalid data, applying NumPy broadcasting, and creating Matplotlib visualizations and animations were the most challenging parts of this assignment.
